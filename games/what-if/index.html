What the game shows

The loop

An operator writes an intent in plain words. An LLM agent turns it into an action (here: the scheduler for the cell). The network runs and reports KPIs, and the agent writes a report. Then the operator asks: what if I had phrased it differently?

Why re-running is not an answer

Running the new intent again changes two things at once: the agent's random choices and the conditions in the network. In the game those are the dice and the weather. You cannot tell whether a different outcome came from your words or from luck.

Rewind: counterfactual generation

The paper models operator, agent and network as one structural causal model. The agent's dice are known. The network's hidden conditions are inferred from the run you saw (abduction, using a digital twin). Then the new intent is replayed with the same dice and the inferred conditions.

Conformal counterfactual generation

The twin is only a model, so one rewind can be off. The paper asks for several, keeps candidates that pass a quality and a diversity test, and stops when confident. Thresholds are calibrated on past episodes so the set contains a faithful answer with a guaranteed probability.
